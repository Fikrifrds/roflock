# Code of Conduct

Roflock should be a constructive, technically rigorous community. Participants
must be respectful across issues, pull requests, reviews, discussions, and
other project spaces.

Expected behavior includes assuming good faith while evaluating evidence,
welcoming different experience levels, giving actionable review feedback,
crediting others' work, disclosing conflicts, and protecting private/security
information.

Unacceptable behavior includes harassment, discrimination, threats, sexualized
attention, doxxing, publishing private correspondence or vulnerability details
without permission, sustained disruption, and retaliation against reporters or
reviewers.

Maintainers may edit or remove content, lock discussions, reject contributions,
or temporarily/permanently restrict participation when necessary. Enforcement
should be proportional, documented privately, and avoid exposing reporters.

Report ordinary conduct concerns privately to the repository owner through
their GitHub profile. If a concern also involves a vulnerability, use the
private channel in [SECURITY.md](SECURITY.md). Do not place sensitive details in
a public issue. The current single-maintainer structure cannot provide an
independent appeals body; if the maintainer is the subject, reporters may ask a
trusted GitHub platform representative or relevant community moderator for
help.
