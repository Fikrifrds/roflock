# Roflock CLI

Roflock is a local-first compiler and governed runtime for defining AI coding
teams in readable `.roflock` workflow files.

```bash
npm install --global roflock
roflock --help
roflock check workflow.roflock
roflock daemon start
```

The package includes the language compiler, runtime CLI, and local daemon. It
does not require a Roflock Cloud account. Install and authenticate a supported
agent CLI separately before starting live coding runs.

Documentation and source: <https://github.com/Fikrifrds/roflock>
